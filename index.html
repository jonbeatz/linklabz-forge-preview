Forge reference

Surfaces + keys. Lanes are home.

Operator cheat sheet for LinkLabz Forge. Open anytime from ? on the command island — glass lightbox on desktop, full-sheet on mobile. No side key. No extra chrome bar.

Surfaces

Lanes — Canonical home — decide where each review lives.

Drop three stem-splitter links into Inbox in the morning; by lunch two are Try It, one is Skipped with a one-line why — board stays honest without a chat dump. Tip: Filters and lane: search act on this model. Don’t invent a fifth “maybe” lane.

Bento — Same lane model, denser grid — compare cards side by side.

Flip to Bento when ranking three “Try It” VST tools; scan ratings and Goes-to chips without scrolling magazine rows. Tip: Toggle back to Lanes when you’re triaging, not comparing.

Cover Browse — Optional Browse lens over Try / Promoted / Favorites — still opens the same detail drawer.

Flip through Promoted favorites like a short stack before a Cursor session; pick one, open drawer, copy the brief. Tip: No floor reflection. Cover is a lens, not a second board. ← → moves the stack when Cover is on.

Reviews — Full review cards — verdict, rating, recommendation, cherry-picks, Cursor brief.

Open StemKit parked as “inspect only”; copy bridge note into Shared Notes without rebuilding the write-up. Tip: Protected seeds lock so Reset doesn’t wipe harvest you already trust.

Bookmarks — Typed quick-saves when a full review ceremony is overkill.

Save a Divi tutorial as Tutorial + one-line note; graduate to a Review later if it earns a verdict. Tip: Duplicate URL guard is on — don’t fight it; update the existing bookmark instead.

Spitballs — Raw ideas before they deserve a lane.

Capture “Explorer Fast Copy toggle + parallel jobs” mid-chat; Graduate → Inbox when you’re ready to review for real. Tip: Spitballs aren’t decisions. If it has a verdict, it’s a Review.

To-do — Action queue tied to projects — severity, park, inline edit, clear done.

After Evaluate on a card, accept the linked to-do; filter High + Active before a Vader build block. Tip: Palette capture: todo buy coffee or t buy coffee then Enter.

Detail drawer — Sticky amber strip for one card — lane, evidence, markdown, bridge note, linked to-do.

Check evidence, Copy Markdown into a Bridge doc, leave the list context behind the drawer. Tip: Esc closes drawer (and palette/modal/help first if those are open).

Command island — Search, shelf jump, Download/Load, session chip, ? Help, and the ⌘K / Ctrl+K palette.

Type lane:try or project:reWavz without hunting filter chips; run “Toggle layout → Bento” from the palette mid-flow. Tip: Session · Dirty means Download before a risky Load/Reset. Help lives on the island — tap ?, don’t look for a side panel.

Card Swap — Manual stack of up to three Try It reviews. Lives on Tools only, not on the main board. The island Card Swap button jumps here.

Open RoboSync, UVR GUI, and Noizefield as a “this week’s trial stack” on the Tools shelf. Tip: Max 3, arrows only. Never auto-rotate the main Lanes board into Card Swap.

What’s experimental

  • Cover Browse — optional Try / Promoted / Favorites lens; same drawer; no floor reflection.
  • Card Swap — max 3 manual cards on Tools only. Not a board mode.
  • Lab — facet filters, project combobox, Workspace mega menu, Band and Coast lenses, gold foil on Try It / top-rated cards, liquid glass on the island. Turn Lab off to use the classic selects. Lanes stays home.
  • Load workspace — replaces the current board (no merge/upsert yet). Download first.
  • Master Muse — Trinity’s board remains source of truth until Jon says otherwise. Forge is the amber Pages challenger.
